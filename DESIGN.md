# Sistema visual NEXUS

Modo: operar. Extensión de los cuatro componentes existentes, conservando estética definida en PRODUCT.md.

- Fondo: #060B14; paneles: #0B1220; texto: #E6EDF7.
- Acción principal y proyección: #67E8F9; advertencia: #FCD34D; peligro: rosa.
- Inter para lectura; JetBrains Mono tabular para telemetría. Fallback local cuando no hay red.
- Contenedor máximo 1440 px; margen 32 px desktop, 16 px móvil.
- Telemetría: cinco columnas, tres bajo 1100 px, una bajo 640 px.
- Subsistemas existentes: tres columnas desde md, una en móvil.
- Foco visible cian; controles de al menos 44 px; movimiento reducido respetado.
- Gráfico SVG acompañado por tabla accesible; color reforzado por texto y valores.

Verificación visual pendiente: ningún navegador conectado durante implementación. Detector mecánico sin hallazgos; esto no demuestra contraste ni responsive en navegador.
